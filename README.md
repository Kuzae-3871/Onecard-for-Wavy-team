# 🃏 원카드 온라인

링크를 공유한 사람들끼리 실시간으로 즐기는 원카드 웹게임 (2~6명).

## 실행 (로컬)
```
npm install
npm start
```
→ http://localhost:3000 접속 → 닉네임 입력 → **방 만들기** → **링크 복사**해서 친구에게 공유.

## 인터넷에 배포 (Render 무료)
1. 이 폴더를 GitHub 저장소로 올림
2. https://render.com → New → Blueprint (또는 Web Service) → 저장소 선택
3. `render.yaml` 자동 인식 (build: `npm install`, start: `npm start`)
4. 발급된 `https://onecard-xxxx.onrender.com` 주소로 접속해 방을 만들고 링크 공유

> Railway, Fly.io 등 WebSocket을 지원하는 Node 호스팅이면 어디든 동작합니다.
> Vercel/Netlify 같은 정적·서버리스 호스팅은 실시간 소켓 서버를 돌릴 수 없어 불가.

## 규칙
| 카드 | 효과 |
|---|---|
| 기본 | 바닥 카드와 모양 또는 숫자가 같으면 냄. 낼 게 없으면 1장 받기 |
| 같은 숫자 여러 장 | **바닥에 이미 그 숫자가 깔려 있을 때만** 동시에 냄 (바닥 ♥5 → ♠5·♦5) |
| 2 | 공격 +2 · 방어: 2, 같은 모양 A, 조커 |
| A | 공격 +3 · 방어: A, 조커만 |
| 흑백조커 | 공격 +5 · 방어: ♠A, 컬러조커만 |
| 컬러조커 | 공격 +7 · 방어 불가 |
| 7 | 모양 변경 |
| J | 다음 사람 점프 |
| Q | 방향 반대, 낸 사람 차례 끝 |
| K | 한 장 더 (같은 모양, 또는 다른 모양의 K). 없으면 1장 받기 |

- 공격은 누적 (흑백조커 + ♠A → 다음 사람 8장)
- 한 장 남으면 **원카드!** 버튼. 다른 사람이 먼저 누르면 1장 받음
- 첫 패 7장, 20장 이상이면 파산. 덱이 떨어지면 낸 카드를 섞어 계속
- 첫 판 선은 랜덤, 같은 방에서 다음 판은 전 판 1등이 선
- 한 명 남을 때까지 진행해 순위 결정 (파산자는 늦게 파산한 사람이 위)
- **게임 포기**(게임 화면 우측 하단): 포기한 사람은 이번 판 꼴등(파산자보다 아래), 패는 몰수해 덱에 섞고, 그 사람에게 걸려 있던 공격은 무효. 남은 사람들은 계속 진행하고 방도 유지
- 사람이 모두 끝나거나(1등·파산·포기) 빠지고 컴퓨터만 남으면 남은 판은 패가 적은 순으로 순위를 정해 바로 종료
- 1등이 정해지면 모두의 화면에 👑 Winner! 연출 → 결과창에서 **한 판 더 / 이 방에 남기 / 메인 홈으로** 선택
- 방장이 턴 제한시간(기본 30초) 설정 가능. 시간 초과 시 자동으로 받고 패널티 1장 더 (공격 중이면 누적 장수 + 1)

## 컴퓨터와 하기
- 홈에서 **컴퓨터와 하기** → 컴퓨터 2명이 들어간 방이 바로 만들어짐
- 대기실에서 방장이 **+ 컴퓨터 추가 / 빼기** (최대 6명, 사람과 섞어서도 가능)
- 컴퓨터는 서버(`bot.js`)에서 같은 규칙으로 판정받으며 플레이: 공격은 막을 수 있으면 가장 약한 카드로 막고, 평소엔 공격 카드를 아끼다가 다음 사람이 1~2장 남으면 공격, 같은 숫자는 한꺼번에 털기, 7은 가장 많은 모양으로 변경
- 원카드: 컴퓨터는 자기 원카드를 외치고(가끔 늦음), 사람이 깜빡하면 2~4초 뒤 잡아냄

## 조작
- 낼 수 있는 카드를 **탭하면 바로** 냄 (서버 응답을 기다리지 않고 카드가 먼저 날아가고, 거절되면 손패로 되돌아옴)
- 못 내는 카드를 탭하면 카드가 흔들리며 이유가 짧게 표시됨
- 바닥과 같은 숫자를 여러 장 갖고 있으면 카드 위에 **1장만 / N장 모두** 선택이 뜸 (누른 카드가 맨 위)
- 7 은 카드 옆에 ♠♥♦♣ 가 바로 뜸
- 덱 탭 또는 "카드 받기" = 받기 / 공격 받기
- 낼 수 있는 카드가 없으면 받기 버튼만 깜빡이고(공격 중이면 빨간색) 나머지 버튼은 흐려짐
- 되돌릴 수 없는 **게임 포기**만 확인창을 거침

## 구조
- `game.js` – 규칙 엔진 (모든 판정은 서버에서)
- `server.js` – Express + Socket.IO, 방 / 재접속 / 턴 타이머 / 컴퓨터 진행
- `bot.js` – 컴퓨터 플레이어 전략
- `public/` – 클라이언트 (바닐라 JS)
- `npm test` – 규칙 시나리오 + 무작위 3000판 시뮬레이션 + 컴퓨터 2000판 검사
